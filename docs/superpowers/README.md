# 设计、计划与实施记录

此目录保留每个阶段当时形成的技术设计、执行计划和实施证据。它是工程历史资料，不代替 [`docs/README.md`](../README.md) 的当前产品方向和 [`docs/XmovAvatar三个关键里程碑实施计划.md`](../XmovAvatar三个关键里程碑实施计划.md) 的当前里程碑状态。

## 目录用途

- `specs/`：阶段设计、实施记录和验收记录。按记录日期理解；文中“下一阶段”“下一步”只描述当时的接续安排。
- `plans/`：M1/M2 阶段执行时保存的计划快照。原始步骤、勾选框和命令用于追溯计划，不是当前任务列表。
- `archive/`：已被当前路线取代的详细方案，保留用于理解早期范围和决策过程。

## 状态判定

判断某项能力是否已实现、验证或通过真人验收时，以当前里程碑状态页及对应实施/验收记录为准。构建通过、自动测试通过和真人验收是不同证据，不能互相替代。

旧计划不删除，以保留实现过程与边界决策。新增计划只在明确启动一个新里程碑后加入 `plans/`，并在文档入口标明它是当前活动计划。
