# M2.4 实时姿态反馈界面实施记录

日期：2026-10-01。分支：`feat/pose-shoulder-loop`。

## 本阶段交付

在独立 Pose Lab 页面接入 M2.2 规则和 M2.3 会话控制器，主应用保持原有路由。画面仍在浏览器本地生成姿态关键点；本阶段增加界面与会话接线，没有增加视频上传、语音、Xmov 或大模型调用。

用户上一条明确选择先开发、暂不自动测试，本阶段沿用该选择。不新增、修改或运行自动测试，也没有代用户开启摄像头执行真人验收。

## 用户流程

1. 打开 `/pose-lab.html`，点击「开启摄像头」，等待姿态识别就绪。连接过程中可以点击「取消连接」。
2. 画面显示人体关键点，训练面板显示本人左右臂角度、80°–105°目标、躯干倾斜、画面范围和全部姿势提示。
3. 摄像头和模型就绪后，可点击「开始训练」。只用随后新推理结果确认稳定；未检测到人体时，会提示让肩、肘、髋部入镜。
4. 正确姿势先稳定500ms，再开始保持3秒。角度和进度随实际识别结果更新；无效姿势立即清零。
5. 可以「暂停训练」「继续训练」或「结束训练」。继续训练重新确认稳定；结束训练停止姿态计算，清空测量，保留摄像头预览。再次开始会重新调度姿态识别。
6. 完成后显示完成提示；允许放下双臂，不追加错误纠正。点击「再做一次」才开启下一次训练。
7. 点击「关闭摄像头」停止摄像头和训练，清空测量。切换来源同样清空旧会话。

性能、归一化肩宽/躯干高度和关键点可见度保留在「识别详情」中。显示的左右以本人为准；视频/骨架镜像只属于显示，数据不交换。画面容器沿用源视频宽高比。

## 实现边界

- `PoseFeedbackWidget`：只渲染测量、会话快照与控制按钮。计时显示向下取十分之一秒，避免未完成时提前显示3.0秒；角度显示不会反过来参与规则判断。
- `usePoseTrainingSession`：持有控制器、最新本地评估和最新结构化事件；只在真实推理回调中提交样本，使用 `performance.now()` 作为单调观察时间。
- 最新事件只保留一条，不包含原始关键点或视频；暂停、停止和过期时清空，供 M2.5 后续接入。
- 每50ms检查一次新样本是否过期，只调用tick取消连续性，不增加保持时间。超过既有250ms上限后，清空实时测量和骨架，显示等待新画面；推理性能显示0FPS。
- 开始/继续的处理器检查摄像头模型就绪和页面可见，随后等待新样本，不能用 React 中缓存的上一帧开启保持。开始训练会重新调度已停止的识别循环。
- 页面隐藏会暂停训练并清空实时测量；返回后需显式继续。推理异常暂停训练，关闭并丢弃故障适配器和循环；关闭后重新开启摄像头会创建新的模型运行时。
- 摄像头轨道结束会停止会话/推理/轨道并显示可恢复错误。切换、关闭、卸载时解除轨道监听、取消过期检查并清理资源。
- 过期的异步启动只释放它自己持有的流，不能关闭随后启动的新摄像头。既有 generation/run gate 继续阻止旧回调更新状态。
- `PoseLabView` 的可选 training 属性保留独立探测视图的调用方式；实际 PoseLabPage 始终提供训练面板。

## 真人基础流程确认（2026-10-01）

用户报告做了两三次双臂抬至肩部高度；询问是否每次启动保持计时并在保持3秒后显示「训练完成」，用户回答「每次都计时并完成了」。

据此记录：重复抬臂 → 页面保持计时 → 训练完成的基础成功流程通过，依据为用户真人操作与确认。次数按用户描述保留为2–3次，没有另行记录视频、截图或精确毫秒测量。

此确认没有覆盖故意保持单臂过低、短暂失效后计时取消、暂停/继续、结束后再次开始、摄像头切换/断开、页面隐藏或故障恢复，也没有确认左右纠正标签及实机FPS。这些仍保留为后续验收项，M2.5播报/数字人动作和M2.6完整闭环尚未验收。

## 实施选择与后续成本

- 沿用当前功能分支；需要隔离时再拆工作目录。
- 摄像头与训练分开控制。原计划结束训练继续推理，审查后按原设计section19改为结束时停止推理；开始/继续在就绪后等待新样本，避免停止后没有新样本导致无法再开始。流程仍需真人验收后调整。
- 用50ms检查既有250ms样本时效；目标电脑若推理较慢，需实测调节上限，避免有效动作频繁重置。
- 任意推理异常都重建运行时；具体异常是否损坏图没有复现，代价是恢复时重新加载模型。
- 时序、浏览器调度、外观、键盘/读屏、真人左右识别和实际停止行为均待后续验收。
- 镜头远近沿用 M2.2 的待标定状态，需实测后配置阈值；没有新增距离估计。
- 原视频就绪等待机制继续沿用 M2.1，需要时在目标浏览器验收后调整；文档中多余标题已修正。
- 固定播报/Xmov/事件消费属于 M2.5，网络边界、端到端中断和真人完整反馈属于 M2.6，须各阶段集成验收。本阶段不验证医疗/运动疗效；若扩展这类主张，需另行评估。
