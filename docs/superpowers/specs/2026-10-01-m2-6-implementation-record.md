## 本轮改动

- 摄像头和数字人放在同一练习行；姿势角度、计时和诊断区域移到下方。宽屏并排，小屏为可读的纵向布局。
- 记录姿态稳定/完成事件 → Xmov SDK 本地 `speak` 调用的单调时钟间隔。面板同时明确：当前 JS SDK 的语音开始回调只有全局状态字符串，没有请求 ID，无法可靠归属于某条训练反馈，因此不伪造第二段计时，需真人按听到语音确认回应耗时。
- 时间使用浏览器 `performance.now()`；不发送日志、帧、关键点或数字人凭据到新增服务。
- Bridge 不再让正常反馈派发等待上一段语音 Promise 完整播放；仍单独跟踪未结算的 SDK 调用。取消时立即打断，迟到调用只在没有更新一轮反馈的情况下做代次保护的尾部清理，避免清理操作误伤新提示。
- SDK 调用失败会保持为终态错误，不会被稍后的“已提交”更新覆盖；即时同步抛错也不会被计作已提交。
- 新一条反馈前显式切换到 Xmov `interactiveidle`。官方 JS SDK 文档也说明全文本 speak 后续调用建议经 `interactive_idle` 状态切换。[Xmov JS SDK 接入说明](https://xingyun3d.com/developers/52-183)
