# M2.5 — 固定语音与数字人反馈实施记录

日期：2026-10-01。分支：feat/pose-shoulder-loop。

## 本轮实现

- 独立 Pose Lab 增加“数字人陪练”面板，由用户点击连接；摄像头和训练仍单独启动。
- 开始训练发送固定动作说明与 warm_up；稳定正确发送“对，就是这里，保持三秒。”与 confirm；完成发送“一组完成，可以放下双臂。”与 encourage。
- 错误提示按身体可见、镜头范围、躯干、左右臂选择一个主要问题。同一主要问题即使次要问题改变也不重复播报。提示不擅自声称另一条手臂已正确。
- 动作通过 M1 Action Registry 验证后解析；训练层没有原始动作语义。打招呼是社交反馈，未作为肩部示范动作。
- 固定语音和 KA 放进同一个已转义的 SSML 请求；不继承聊天的表情/动作计划。SDK 提交成功只表示请求已交付，不等于实际播放完成。
- 会话 hook 直接逐个交付稳定事件，避免 React 批量渲染丢事件。数字人连接/重连不重放历史事件。
- 暂停、结束、相机变化/关闭/断流、识别失败、页面隐藏和卸载撤销反馈；保持被打断或未完成会话观测过期也会立即撤销正确提示。已经完成的一组不会因普通观测过期否定完成结果，但显式停止/隐藏/断连仍撤销反馈。
- Bridge 用世代、AbortSignal、provider 身份和串行 SDK 调用防止旧反馈再次发送；取消时先请求打断，再清除可能较晚交付的旧 SDK 请求。慢 SDK 请求仍须返回才能完成后续清理。
- 初始化被断开/卸载后，迟到的 SDK 实例由所属初始化释放；错误不再恢复就绪。数字人反馈失败独立显示，不改变姿态会话。
- 训练页只显示非技术连接提示；原有数字人页面保持默认展示和公开调用接口。

## 使用顺序

1. 打开 http://127.0.0.1:5273/pose-lab.html。
2. 点击“连接数字人”，等连接就绪。未配置/失败时可继续使用摄像头练习。
3. 开启摄像头并开始训练，先故意让一侧手臂偏低，听对应侧的简短纠正。
4. 双臂到肩部高度后听确认，连续保持3秒，观察完成鼓励。
5. “暂停训练”“结束训练”“关闭摄像头”会取消反馈；连接数字人不自动开始相机或训练。
