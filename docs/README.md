## 当前产品方向

产品以真实落地场景、用户体验和长期价值为目标。用户提出的长期体验方向是：大场景、数字人为主要陪伴对象、语音优先，日常交互尽量不依赖屏幕文字；摄像头和姿态识别是支撑交互的能力。

具体目标用户、首发场景、持续需求和商业模式仍待验证，当前不预设答案。Pose Lab 是阶段性验证工具，不是商用产品界面。

详见：[产品方向与技术决策记录](./2026-09-29-XmovAvatar赛道产品方向与技术决策.md)。
