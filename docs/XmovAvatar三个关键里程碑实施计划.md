# XmovAvatar 里程碑状态与后续路线

更新日期：2026-10-01。本文取代 2026-09-29 的初版“下一阶段计划”，作为当前里程碑状态摘要。具体实现证据以各阶段记录为准；商业产品目标不等于已经确定产品场景或开发排期。

## 产品目标与阶段边界

长期目标是面向真实场景和持续用户价值的商用产品。用户提出的大场景、数字人为主、语音优先是体验方向；目标用户、首发场景及商业模式尚未验证。

当前 Pose Lab 只用于验证摄像头、人体姿态、单动作训练和数字人反馈。完成这个验证窗不代表商用产品体验已经设计完成。

## 当前待办：完成 M2.6 真人验收

1. 刷新 `http://127.0.0.1:5273/pose-lab.html`，确认笔记本视口内无需滚动就能看到摄像头、数字人和主要训练操作。
2. 实际完成一次训练，观察动作完成后数字人的语音回应；目前用户只反馈“比之前快一点”，没有精确秒数。
3. 记录约 30 秒的 FPS/推理耗时、左右手跟踪、肩宽和躯干高度，并确认暂停、结束、断连/打断行为。

M2.6 的生产构建已通过。根据用户选择，本阶段没有新增或运行自动化测试；构建结果不能替代真人验收。新的单屏布局也尚未由用户确认。

## 后续候选：M3 Agent Tool Calling（未开始、未排期）

初版技术方案建议把已验证能力包装为 `pose_monitor`、`avatar_action` 和 `show_widget`，再由 Agent 按交互需要编排。该方案保留为候选方向，不代表必须立刻开发。

在启动 M3 前应先完成 M2.6 验收，并围绕真实用户场景确认 Agent 编排带来的具体体验或运营价值。若用户任务可以用清晰的确定性流程完成，就不因已有工具接口而额外引入 Agent 决策。
