## 协作安排

基线为 `feat/pose-shoulder-loop`；成员分别用 `team/qa-m2-6`、`team/ui-m2-6`、`team/product-scenario`。通过 PR 交付，由主开发审查合并。

报告建议放在 `docs/team-work/qa/`、`docs/team-work/ui/`、`docs/team-work/research/`；合并与验收决定放在 `docs/team-work/integration/`。这些是交付路径建议，不代表成员已经提交。

核心运行逻辑由主开发负责；本轮 `pose-lab.scss` 样式优先由前端辅助负责；测试成员的小开发由主开发逐项指定，避免同时修改同一文件。

首先完成 M2.6 真人验收与问题处理，并开展真实场景研究。M3 的具体范围仍待确定。岗位任务书不是自动化测试或商用产品已验收的证据。
